# 🏝️ Unity · 3D射击小游戏（2025）

基于 **Unity 3D** 开发的第三人称射击小游戏。玩家操控主角在一个 3D 岛屿场景中，射击消灭不断生成的敌人，管理自身与敌人的生命值。

---

## 🎮 游戏玩法

| 操作 | 按键 |
|---|---|
| 移动 | W / A / S / D |
| 射击 | 鼠标左键 |

消灭不断生成的敌人，小心它们会主动追踪你！

---

## ✨ 功能特性

### 场景与视觉
- 使用 Unity 地形工具搭建的**多平台 + 斜坡 3D 岛屿环境**
- 障碍物、平台与装饰物摆放，增加游戏复杂度与视觉吸引力
- **自由跟随相机**：平滑跟随主角移动与旋转，保证稳定视野
- 绿色环境光源烘托氛围 + 点光源突出关键区域

### 游戏逻辑
- **主角移动与射击**：WASD 移动，鼠标指向射击，子弹飞行一段距离后自动消失
- **敌人 AI**：自动检测主角位置并追击，具备基础寻路能力（可绕过障碍物）
- **动态刷怪**：游戏开始及特定条件下，在场景多个出生点随机生成敌人
- **生命值系统**：UI 显示主角生命值；敌人死亡后销毁，主角死亡后游戏结束

### 🚀 创新机制：烟雾子弹
子弹射出后会**弥漫向四周环境、慢慢消散**的特殊效果，增加游戏的可玩性与趣味性。

### 音效
射击、敌人生成、受击等关键事件均有音效反馈，与动作同步，增强沉浸感。
